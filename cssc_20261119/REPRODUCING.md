# CSSC computational archive

The code archive contains the five-method estimators, tariff optimizer, four-fold held-out CRPS selector, Monte Carlo runners, and audit scripts. Python 3.12.14 and the packages in `exp1/requirements_cssc.txt` were used for the revised runs. Install the direct dependencies with `python -m pip install -r exp1/requirements_cssc.txt`. Every reported full run has a manifest with source hashes, row counts, and a `PASS` completion state. The data ZIPs preserve the original 10,000 primary histories, decision and numerical-audit outputs, and derived tables. The full fitted-law JSONL checkpoints are regenerated by the primary runner from the preserved histories and fixed seeds.

## Reconstruct the primary histories

Extract all five `CSSC_History_Part*.zip` files into one portal directory, retaining their internal paths. From the extracted code archive, run:

```text
python exp1/code/revised/reconstruct_cssc_histories.py --portal PORTAL_DIR --output HISTORY_DIR
```

The reconstruction checks both Parquet files against `offline_history_manifest.json`. The event and monthly-maxima archives, not the final decision table, are the inputs to the primary Monte Carlo runner.

## Reproduce the revised primary experiment

Use a project root containing the extracted `exp1` directory. The full primary run uses 10,000 histories, 24 training months per history, five methods, nine tariff cells, four-fold month-level held-out CRPS for TAIL threshold selection, a 500-resample final shape diagnostic, and no artificial fitted-law upper bound:

```text
python exp1/code/revised/run_primary_no_nominal_ks.py --base-repo exp1/code/legacy_engine --data HISTORY_DIR --run-manifest HISTORY_DIR/offline_history_manifest.json --output CSSC_REVIEW_REVISION_20261112/primary_cv_crps_decisions_20261115 --start 0 --end 10000 --chunk-size 25 --workers 8
```

The runner supports `--resume` and verifies saved chunk hashes before reuse. The selector's full-run outputs are recorded separately in `CSSC_Data_Part4.zip`. The final decision audit and numerical-bound run use the manifest and 400 fitted-law JSONL chunks under `primary_cv_crps_decisions_20261115/support_policy_audit/`.

```text
python exp1/code/revised/audit_primary_cv_crps_decisions.py --decision-manifest DECISION_AUDIT_DIR/audit_manifest.json --selector-run SELECTOR_RUN_DIR --output PRIMARY_OUTPUT_DIR/full_audit.json --require-complete
python exp1/code/revised/analyze_primary_no_nominal_ks.py --base-repo exp1/code/legacy_engine --data PRIMARY_OUTPUT_DIR --out ANALYSIS_DIR --expected-replications 10000
python exp1/code/revised/compute_primitive_bounds.py --base-repo exp1/code/legacy_engine --audit-script exp1/code/legacy/run_support_policy_audit.py --audit-root DECISION_AUDIT_DIR --decision-file PRIMARY_OUTPUT_DIR/raw/primary_decisions_10000.csv.gz --out BOUNDS_DIR --workers 5
```

`SELECTOR_RUN_DIR` contains `full_audit.json` and the 200 selector CSV files. `DECISION_AUDIT_DIR` is the single signature-named folder produced under `PRIMARY_OUTPUT_DIR/support_policy_audit/`. The numerical audit reads the saved fitted laws; it does not fit a second set of models.

## Additional experiments

The independent negative-binomial–Weibull challenge uses the same five methods and 10,000 new histories:

```text
python exp1/code/revised/run_nb_weibull_cv_crps.py --base-repo exp1/code/legacy_engine --out CSSC_REVIEW_REVISION_20261112/nb_weibull_cv_crps_20261115 --replications 10000 --workers 4 --chunk-size 25
```

The high-contract-quantile analysis re-evaluates the primary fitted laws at three tariff targets. It requires the complete primary audit at the project-relative path shown above:

```text
python exp1/code/revised/run_high_pstar_cv_crps.py --workers 5 --resume
```

The external rolling-validation runner and configuration are in `external/`; its released run summary records 3,456 candidate-fold rows and 224 prediction rows, including checks that each training month is held out in turn and the test month is used only for final scoring. The manufacturing-load tariff charges are counterfactual calculations under an illustrative common tariff.

The manuscript and supplementary LaTeX source are supplied separately in `CSSC_Manuscript_Source.zip` and `CSSC_Supplementary_Source.zip`. The portal manifest lists the SHA-256 hash of each uploaded file.

## Review addenda and table provenance

The adaptive Wasserstein audit uses the archived fitted laws and decision records. Its full run produced 50,000 law-level brackets and 450,000 decision-level checks. The matched event-level ablation uses 10,000 histories in each of the primary and negative-binomial–Weibull settings. The common-cell and contract-action analyses reuse saved decision arrays.

```text
python exp1/code/revised/compute_adaptive_w1.py --help
python exp1/code/revised/verify_adaptive_w1.py --help
python exp1/code/revised/run_tail_ablation.py --histories 10000 --workers 8
python exp1/code/revised/analyze_high_pstar_common_cells.py
python exp1/code/revised/analyze_contract_action_errors.py
```

The complete outputs and SHA-256 audit manifests are under `data/source/adaptive_w1/`, `data/source/tail_ablation/`, `data/source/high_pstar_cv_crps_20261115/`, and `data/source/contract_action_errors_20261119/` in the data archives. Table S12 reports the complete primary paired contrasts, Table S13 reports analytic tariff radii, Table S14 reports numerical sufficient-condition checks, and Table S15 reports simultaneous paired intervals. The interval source is `primary_cv_crps_analysis_20261115/analysis/audit/focal_maxt_intervals.csv`. Figure 4 uses `data/plot/Figure4_external_selected.csv`; panels (e,f) use the saved illustrative-charge rows in `data/source/dgp_external_support/`. These external charges are calculations under a shared illustrative tariff.

Rebuild the manuscript, supplementary tables, and Figure S3 with `python exp1/code/compose_cssc_submission.py`; the portal builder then packages these source files. The package versions are pinned in `exp1/requirements_cssc.txt`. The scripts' `--help` output specifies optional input and output paths for a separate rerun.
