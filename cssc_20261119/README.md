# CSSC submission revision — 19 November 2026

This directory contains the revised manuscript and Supporting Information, computational scripts, and new experiment outputs used in the CSSC submission. The complete primary histories, decision records, and rolling external inputs are distributed in the journal submission data archives listed in CSSC_Portal_Manifest.csv.

The manuscript and Supporting Information PDFs are in Manuscript/ and Supporting_Information/. Their LaTeX sources are included with figures and tables. The Data and Code Availability statement in the main manuscript links to this repository.

The adaptive Wasserstein audit covers 50,000 fitted laws and 450,000 decisions; the matched event-level ablation covers 10,000 histories in each of two mechanisms. The outputs for these addenda are in data/source/. REPRODUCING.md gives commands and provenance. The older top-level data and audit code belong to an earlier article archive; use this directory for the current revision.

The external illustrative charges are calculated from observed manufacturing loads under a shared hypothetical tariff.
